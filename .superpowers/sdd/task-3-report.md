## Concerns
- `SteeringEvent` is duplicated in the broker: the session package publishes `session.SteeringEvent` and the TUI's `pumpSteeringEvents` signature uses `*pubsub.Broker[session.SteeringEvent]` directly (no local `tui.SteeringEvent` re-export). This matches the "prefer the canonical type" approach used in Task 2 for `JobEvent` and avoids a lossy conversion layer; the only downside is that `events.go` no longer carries the steering event constant, which makes it slightly less discoverable as a TUI-side events file. Acceptable trade-off.
- The steering test asserts the injected message reaches the LLM (via `p.requests[1].Messages`) rather than `state.Messages()`. Steering is an ephemeral mid-turn nudge and is not added to the session transcript by design; persisted user messages only happen via the Enter submit path. This is a sensible separation (steering == ephemeral nudge; typed submission == first-class user turn) but the test description in the plan said "the steering message must appear in the message history" which I read as the LLM-side history, not the in-memory session tree.
- `submitTurn` was originally intended as a shared helper for both the normal Enter path and the follow-up Enter path. Inlining it kept the Enter case returning `Model` (value) rather than `*Model`, which was required to avoid breaking `TestEnterAppendsInputAndClearsPrompt`'s type assertion. The duplication is small and the dual-purpose helper was a net negative for readability.
- The follow-up Enter path uses a new `session.State.PopSteering()` (singular, FIFO) accessor rather than calling `DrainSteering()` and slicing the head back on. This is a small API addition the plan didn't call for but the alternative (drain-all + re-push-tail) is racy against concurrent `PushSteering` calls. The test `TestEnterOnEmptyDrainsQueuedFollowUp` exercises it.
- `progress.md` was not included in the commit because `.superpowers/` is gitignored. The ledger is updated on disk but not in git; this matches the existing pattern in Tasks 1 and 2.
