**How this plan is written.** No prototype was built, and the plan embeds no implementation code. The Contracts section holds declarations only. Every other step states its decision in prose. Executing the plan also tests how well Marshal follows a plan. "As `X` does" means `X` exists and is the model to copy.

**Goal:** under the local profile, a fleet agent on a local project runs its session on that project's `marshal acp --viewers` child, beside the TUI's sessions, instead of on a host process of its own.
- The agent keeps its bridge ID, its workspace record, its event log, its live state and its lifecycle.
- The project child tells the fleet's sessions from the TUI's. The idle sweep, the daemon's listing, an attach and the client-trust mark all leave the fleet's sessions alone.
- Releasing an agent closes its session, never the child.

**Non-goals:**
- **The server profile keeps a child per agent** (H11), and so do containerized agents (H1).
- **Git-sourced agents, workspace agents and agents the egress proxy wires keep a child each** (decision 2).
- **No web UI change and no new REST route.** The fleet's HTTP surface answers as before.
- **No change on the agent side.** A fleet session on a project child is created, prompted and closed by the same ACP calls as on a child of its own.
- **A TUI that resumes a paused agent's stored session is not prevented,** as it is not before this plan. Only a live fleet session is refused to an attach.
- **No changelog entry.**

**Decisions this plan makes beyond the spec** (D10's details block records them):

1. **The registry marks the fleet's sessions,** not the bridge's sessions in general. A project child's registry keeps its registry-wide `ClientTrust` for every session that is not the fleet's, so plan 7's attach path is unchanged.
2. **Only the local profile's plain host agents move:** a local source, no workspace, and no egress proxy running. A git agent's tree is deleted with the agent; a workspace needs a container; and a proxied agent needs an environment of its own. Each keeps its own child, built as today.
3. **One event log and one classifier per project child,** installed before the child starts, as `Attach` requires. The log keeps every session that is not tracked as a client's. A fleet session is then logged from its first notification, even before Spawn has tracked it.
4. **The classifier finds the agent through the fleet's session map.** A notification that arrives during Spawn's `session/new`, before the session's ID is known, reaches the event log but not the live state. `restoreSession` maps the session before it loads it, so a load's replay reaches the live state as it does today.
5. **Releasing an agent closes its session, and a close that fails still untracks it,** so a dead session never keeps the child from lingering.
6. **An attach that names a live fleet session is refused with 409,** before any viewer connection is opened.

## Contracts

### The registry's fleet sessions (`web/bridge/registry.go`)

```go
// On sessionInfo:
	// fleet is true for a fleet agent's session (P4 D10). It keeps a project
	// child running, but the idle sweep, the daemon's listing, an attach and
	// the client-trust mark all leave it alone.
	fleet bool

// TrackFleet tracks id as a fleet agent's session.
func (r *Registry) TrackFleet(id string, cwd AgentPath)

// LoadFleet is Load for a fleet agent's session: session/load without the
// mark, then tracked as the fleet's.
func (r *Registry) LoadFleet(ctx context.Context, cwd AgentPath, id string) error

// IsFleet reports whether id is tracked as a fleet agent's session.
func (r *Registry) IsFleet(id string) bool

// tracksClient reports whether id is tracked and is not the fleet's: a
// client's session, whose events a project child does not log.
func (r *Registry) tracksClient(id string) bool

// forget untracks id and drains its waits without asking the child, for a
// session whose close failed.
func (r *Registry) forget(id string)
```

### The classifier (`web/bridge/fleet.go`)

```go
// agentOf names the agent a session belongs to; ok is false for a session
// that is no agent's.
type agentOf func(sessionID string) (agentID string, ok bool)

// installClassifier chains the fleet's classifier onto child's notifications
// and reg's events, keying each delta by agentOf's answer. It must run before
// child starts, as Attach must.
func (f *Fleet) installClassifier(child *Child, reg *Registry, agentOf agentOf)

// agentForSession is the fleet's session map as an agentOf.
func (f *Fleet) agentForSession(sessionID string) (string, bool)
```

### Agents on project children

```go
// events.go
// attachSessions is Attach for the sessions keep accepts; a nil keep accepts
// every session, which is what Attach passes.
func attachSessions(l *EventLog, child *Child, reg *Registry, keep func(sessionID string) bool)

// projectchild.go, on projectChild (guarded by mu where noted):
	// log is the child's event log, shared by the fleet's sessions on it.
	log *EventLog
	// caps are the capabilities its initialize advertised (mu).
	caps map[string]bool

// fleet.go, on agentRuntime:
	// project is the project child the agent's session runs on; nil for an
	// agent with a child of its own (P4 D10).
	project *projectChild

// onProjectChild reports whether a runs on its project's child (decision 2).
func (f *Fleet) onProjectChild(a Agent) bool

// projectRuntime is startRuntime for an agent on its project's child.
func (f *Fleet) projectRuntime(ctx context.Context, a Agent) (*agentRuntime, error)

// versionSkew is checkAgentVersion's rule: both versions real and different.
func versionSkew(agentVersion, bridgeVersion string) bool
```
