## Goal

- **A bridge can be a relay** for the hosts it names, each with its own join
  secret.
- **A bridge can join a relay** by dialling out. It keeps a small pool of
  reversed connections and serves its own network handler over them.
- **The relay forwards one host's API unchanged** under
  `/api/hosts/<name>/`. The host's own token decides every request.
- **The local daemon joins through user config,** and hands its token to a
  pipe with `marshal daemon token`.

## Non-goals

- Any app change beyond the regenerated `contract.g.dart` and its fixture
  test: plan 4.
- The agent attach, `marshal attach` or the fleet screen over a relay.
- The local daemon acting as a relay through `marshal daemon install`.
- Relay chains (spec D15).

## Decisions this plan makes beyond the spec

1. **Two files.** `web/bridge/hostrelay.go` is the relay side: the table, the
   join route, the forward route and the hosts route. `web/bridge/hostjoin.go`
   is the joiner. `relay.go` is P4's attach relay and is not touched.
2. **Secrets are values in the bridge, files in the command.** `cmd/webbridge`
   reads each secret file and refuses one that grants group or other any
   access. It hands `bridge` the values. The bridge never opens a secret
   file.
3. **The limits are fields.** The spare count (2), the cap (32), the backoff
   (1 s to 30 s), the relay's wait (5 s) and the keep-alive (15 s) are fields
   with these defaults on the relay and the joiner. They are not package
   variables, so a test sets its own without racing another (AGENTS.md's
   rule on package globals).
4. **The reversed connection is a real `net.Conn`.**
   - The joiner dials with `tls.Dialer`, or `net.Dialer` for loopback http,
     writes the upgrade with `Request.Write` and reads the answer with
     `http.ReadResponse`. It then serves the connection through a wrapper
     that drains the response reader's buffer before it reads the socket.
   - The relay wraps its hijacked connection the same way, around the
     hijack's reader.
5. **"Consumed" is the first read.** A joined connection counts as consumed
   when its first `Read` returns data, which is the relay's first request on
   it. That is when the joiner dials a replacement.
6. **The relay's transport per host.**
   - Its `DialContext` takes a fresh joined connection, waiting up to the
     relay's wait.
   - Keep-alives stay on, so a connection is reused after its first request.
   - `MaxConnsPerHost` is the cap, and HTTP/2 is off.
   - The request URL's host is `<name>.relay.invalid`. `DialContext`
     ignores it.
7. **The forward's 503** is the transport's dial timing out. The proxy's
   `ErrorHandler` answers it with spec D14's words, and any other proxy
   error with 502 and the error's text.
8. **Where the join route answers.** Only `ServeHTTP` (the network listener)
   checks for it, before `studioRoute`. The socket answers it 404, because a
   join over the owner's own socket is meaningless.

## Task 2 — the relay's table and the join

**Files:** `web/bridge/hostrelay.go` (new), `web/bridge/http.go`,
`web/bridge/hostrelay_test.go` (new).

1. **The table.** `NewHostRelay` checks each name against the copied rule
   and refuses an empty secret. Each name holds:
   - its secret;
   - its current instance id, and when that instance joined;
   - its last contact;
   - a queue of fresh joined connections;
   - its `http.Transport` (decision 6).
2. **The join route** answers in `ServeHTTP` before `studioRoute`, when a
   relay is set (decision 8).
   - It answers `POST` only.
   - The `Upgrade` header must equal `joinUpgrade`, with `Connection:
     Upgrade`; anything else is 400.
   - The name must be one the table holds, and the bearer value must equal
     that name's secret, compared with `subtle.ConstantTimeCompare`. Either
     failing is 401 with one body, `{"error":"unauthorized"}`, as
     `unauthorized` writes it (`auth.go`).
   - An empty instance header is 400.
3. **Taking the connection.** On success, write the 101 with `Upgrade` and
   `Connection` headers, flush, and hijack. Wrap the connection (decision 4)
   and put it on the name's queue.
4. **Newest instance wins.** A join whose instance differs from the
   current one becomes the current one. Before its connection is queued, the
   older instance's queued connections are closed and the name's transport
   drops its idle connections. A request in flight on an older connection
   finishes.
5. **A closed connection** leaves the queue. A queued connection the joiner
   closes is noticed when it is taken: the transport's dial skips a
   connection whose first write fails.
6. Tests, in `hostrelay_test.go`, against an `httptest.Server` running
   `ServeHTTP` with a relay set, and a raw client written in the test:
   - `TestAJoinNeedsTheNamesOwnSecret`, which uses another name's secret;
   - `TestAnUnknownNameAndAWrongSecretAnswerAlike`;
   - `TestAJoinMustBeTheUpgrade`;
   - `TestAJoinIsTakenOver`, which sends a request down the 101's
     connection from the relay side and reads it at the client;
   - `TestTheNewestInstanceWins`;
   - `TestTheSocketHasNoJoinRoute`;
   - `TestABridgeWithoutARelayHasNoJoinRoute`.

**Verify:** `TMPDIR=/private/tmp/p8-3 go test ./web/bridge -run 'TestAJoin|TestAnUnknownName|TestTheNewestInstance|TestTheSocketHasNoJoin|TestABridgeWithoutARelay' -count=1`.

**Mutation check:** compare the secret with `==` against the first name's
secret, whatever name the join gives. `TestAJoinNeedsTheNamesOwnSecret` must
fail. Restore.

## Task 3 — forwarding and listing

**Files:** `web/bridge/hostrelay.go`, `web/bridge/http.go`,
`web/bridge/hostrelay_test.go`.

1. **Routes.** `SetHostRelay` registers `GET /api/relay/hosts` and the
   prefix `/api/hosts/` on the mux, so both sit behind `bearerAuth` as every
   `/api/` route does.
2. **The forward:**
   - Split the path into the name and the rest, unescaping the name. A name
     the table does not hold is 404, `"no relayed host <name>"`.
   - A rest that is not under `api/`, or is under `api/hosts/` or

   streams as it writes them.

   is true while the current instance has at least one open connection.

## Task 4 — the joiner

**Files:** `web/bridge/hostjoin.go` (new), `web/bridge/daemoninfo.go`,
`web/bridge/hostjoin_test.go` (new).

1. **`NewJoiner`** checks the URL with the copied rule, the name with the
   name rule, and that the secret is not empty. It loads the CA file when
   one is named, as `fleetprofile.TLSConfig` does for a profile, and offers
   only `http/1.1` in its TLS config. The instance id is 16 random bytes,
   hex-encoded.
2. **A join** dials (decision 4), sends the upgrade with the four headers and
   reads the answer.
   - A 101 hands the wrapped connection to the joiner's listener.
   - A 401 records "the relay refused the join for <name>" as the last error.
   - Anything else records the status and the body's first line.
   - The connection gets TCP keep-alive at the joiner's interval.
3. **The listener** is a `net.Listener` whose `Accept` returns joined
   connections, and whose `Close` stops `Run`. `Run` serves `h` on it with
   an `http.Server` that has a `ReadHeaderTimeout` as `main.go`'s servers
   do. It keeps the pool:
   - at start, it dials the spare count;
   - a connection that is consumed (decision 5) dials one replacement while
     the open count is under the cap;
   - a connection that closes dials one when fresh ones are under the spare
     count.
4. **Backoff.** A failed dial or join waits from the minimum, doubling to the
   maximum, and resets on a 101. A 401 is logged once per change of last
   error, and waits the maximum.
5. **`Report`** gives the URL, the name, `connected` (at least one open
   connection) and the last error.
6. **`RelayedHandler`** answers 404 for a path `agentAttachID` matches, or
   one under `/api/studio/`, and passes everything else to `ServeHTTP`.
7. **`SetJoiner`** makes `(*Server).daemon` fill `Join` from `Report`.
8. Tests, in `hostjoin_test.go`, against a relay `Server` from Task 2 on an
   `httptest.Server`:
   - `TestAJoinerKeepsTwoSpareConnections`;
   - `TestAConsumedConnectionIsReplaced`;
   - `TestThePoolStopsAtItsCap`, with the cap set to 3;
   - `TestARefusedJoinBacksOffAndReports`, with the backoff set to
     milliseconds;
   - `TestARelayedConnectionRefusesTheAttachAndTheStudioRoutes`;
   - `TestTheDaemonDocumentReportsTheJoin`;
   - `TestARestartedJoinerTakesItsNameBack`, which starts a second joiner
     with the same name and secret and checks the first one's spare
     connections close.

**Verify:** `TMPDIR=/private/tmp/p8-3 go test ./web/bridge -run 'TestAJoiner|TestAConsumed|TestThePoolStops|TestARefusedJoin|TestARelayedConnection|TestTheDaemonDocumentReportsTheJoin|TestARestartedJoiner' -count=1`.

**Mutation check:** dial the replacement when a connection is accepted rather
than when it is consumed. `TestAJoinerKeepsTwoSpareConnections` must fail,
