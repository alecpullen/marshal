01 · The issue and approach

An approval outlives its connection

Disconnecting deleted pending requests. The transcript returned on reconnect; the unanswered approval did not.

The session now owns the requests. Reconnecting retrieves the same outstanding approval.

Copying requests on reconnect would leave a gap while no client is attached.

The remaining edge case is concurrent answers: resolution must accept exactly one. The factory is making that operation atomic.
