Framed Console

The tray's rounded outline, carried to the rest of the live part of the screen: the prompt, the prompts that replace it, the popup, and the panels. Nothing at the bottom of the screen is tinted any more. The frame does the grouping.

Every "Today" frame is a real capture: marshal at 100×34 with depth = "raised", on qwen3.5-9b and nemotron-3.5 through LM Studio. The proposed frames keep the captured transcript and tray rows and redraw only the chrome. Pick a tab to compare; ● marks the one I'd take.

╭─ A frame means live, or waiting on you

Framed
The tray, the prompt input, anything that replaces the input (access, approval, question, skill gate, sudo), the command popup, docked and full-frame panels, and a drilled-in child.
Not framed
Transcript history: beats, events, answers, code and diffs keep the spine and the gutter.
No chrome tint
The input band goes, as the status line's already has. The only tint left marks work that is still moving: running tray rows and the live thinking row.
Border colour
Muted at rest. Amber when Marshal needs a decision, violet for a question or a focused panel, coral inside a child. The label says the same thing in words, so it still reads without colour.

  • Budgets and hit-testing: the input gains a top border row only at idle, so inputChromeRows grows by one there and the input's click row moves down one.
